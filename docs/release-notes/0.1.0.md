# Pennant 0.1.0

The first public preview: one AI agent that lives on your Mac and does the work.

- Jobs on a schedule, in plain words or cron. Every run gets a thread of its own, and a run ends in a report card.
- Goals: outcomes Pennant works toward on its own, with a board of what's next and a weekly review. Start, pause, edit or delete any goal yourself, or approve the ones it proposes.
- Anything that would publish, send an email, delete or spend money stops at an approval card first. Edit the text, send it back with a note, or reject it, on the Mac or the iPhone. Cards written in Markdown show formatted, with the plain text one click away.
- Any model: OpenAI-compatible endpoints and presets for the major providers, Azure AI Foundry, a ChatGPT account, Ollama, LM Studio, vLLM, Apple's on-device model, with fallbacks when a provider is down or rate-limited. Keys can live in the Vault (your Keychain) instead of a config file.
- Memory with receipts: facts learned after each task, the passages they came from, and what you said always outranks what it guessed.
- It uses your Mac's apps and lets go the moment you touch the mouse.
- Coding runs in your project folders, with Claude Code or Pennant's own engine on any of your models, asks before it deletes or publishes, and can push as its own GitHub App, all set up in Settings › Pennant › Coding.
- Skills are folders you own (the `SKILL.md` format), with every version kept; teach one by doing the task once.
- Connections: a catalogue of MCP servers with one Connect button each, and Microsoft 365, LinkedIn and Reddit built in.
- An iPhone companion that signs in to your own Mac: approvals, threads, reports, memory and the Mac's screen, live. It isn't on the App Store yet; build it from the source.
- View › Zoom In and Zoom Out (⌘+, ⌘−) make the text larger or smaller.
- Updates: Pennant checks pennant.dev once a day, if you allow it, and installs only updates signed by the project.

Requires macOS 15 or later, on Apple silicon or Intel. This is a preview; expect rough edges, and please report them.
