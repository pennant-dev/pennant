# Pennant 0.3.3

Plugins arrive, Pennant asks for your folders itself, and check-ins stay quiet when there's nothing to say.

- **Plugins, a first version.** A plugin adds tools to Pennant and runs in a sandbox of its own. It gets only what you allow, one thing at a time: the network, a secret from Vault, a sign-in command Pennant runs for it, posting in the chat. More › Plugins on the Mac (Plugins on the iPhone) shows each one, what it can use and what it asked for lately. Tools that change things ask you first. The first plugin is for Azure: subscriptions, resources, costs, clusters, logs and alerts. Build it with `Scripts/build-plugin.sh Azure` and install it from the Plugins page or with `pennant plugin install`.
- **Folder access, asked for like everything else.** When macOS stops Pennant from reading Documents, Desktop or Downloads, Pennant notices and shows it with the other permissions. Grant brings up macOS's own prompt. Work that runs into a blocked folder asks then and there.
- **Quiet check-ins stay quiet.** A check-in with nothing to tell you leaves nothing in the chat, however the model words it, including the notes it used to leave for itself. Check-ins keep to their own budget and no longer hold up the chat by asking whether to go on.
- **Stopping a thread stops everything it started.** A skill running in Claude Code, or a coding run started inside a thread, stops with it. While it works, it shows in the thread list and as a progress row with its latest line.
- **The chat hands work to a thread itself** when a reply needs more than a quick answer, instead of refusing.
- **Skills.** A skill you turn off stays off when its files change (`pennant skills disable` and `enable`). Search finds each skill once, at its newest version. Long instructions tell Pennant where the rest is.
- **Approval cards can't be skipped.** A call that claimed an approval it didn't have could send without a card. Now only an approved, unused card for the same text lets it through.
- **Mail times in your time zone.** Microsoft 365 mail came through in UTC, so Pennant could quote times hours off your clock.

Requires macOS 15 or later, on Apple silicon or Intel. This is a preview; expect rough edges, and please report them.
