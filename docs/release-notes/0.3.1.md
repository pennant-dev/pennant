# Pennant 0.3.1

You decide what Pennant looks at when it checks in.

- **On each check-in, also.** Settings › Pennant › Heartbeat has a box for what you want Pennant to do every time it checks in, in your own words: "Check my email for anything that needs me today", "Look at the build status", or nothing at all. Pennant does it with whatever tools and connections it has, so it works with Gmail, Outlook, Yahoo or anything else it can reach, and tells you only what needs you. From the command line: `pennant heartbeat also <what to do>`.
- **No mail check unless you ask for one.** In 0.3.0 each check-in read new mail through Microsoft 365, on by default. It doesn't any more. If you relied on it, write it in the box above.
- **The cost:** a check-in with something in the box is a turn of your model every time, up to the daily cap you set. With the box empty, a check-in still costs nothing unless Pennant's own work needs a look.

Requires macOS 15 or later, on Apple silicon or Intel. This is a preview; expect rough edges, and please report them.
