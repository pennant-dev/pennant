# Pennant 0.3.2

Your Claude Code skills come to Pennant, and a few things that got in the way don't any more.

- **Your Claude Code skills, in Pennant.** Turn on "Claude Code skills" at the foot of Skills (or `pennant skills claude-code on`) and Pennant links the skills in `~/.claude/skills`, your Claude account's skills, and those of the Claude Code plugins you have switched on. They stay in step with the files: edit one in Claude Code and Pennant has the new version. Pennant follows most of them itself, on whatever model you use. The ones that rely on Claude Code itself (subagents, Claude in Chrome, its own tools) run in Claude Code, in a thread of their own, and come back with the result. Pick one from the `/` list in the chat and it goes straight where it runs.
- **/clear and /compact.** Type them in the chat instead of hunting for buttons. `/clear` starts the conversation fresh and blanks the screen; "Show earlier messages" on its line brings the history back. `/compact` folds the conversation into a summary.
- **Cards that run what they say.** Approving a card could fail with "isn't available (is its connector signed in?)" when the model had named the tool its own way. Cards now find the tool however it's written, and check it before the card goes up.
- **Sign-ins that survive a network blip.** A connection that couldn't refresh its sign-in while you were offline used to ask you to sign in again. Now it keeps the sign-in and tries again, and a connection that fails reconnects on its own.
- **Tool calls from GLM and similar models.** Some local servers pass a model's tool call through as text, and it showed up in the chat as `<tool_call>…`. Pennant now reads it as the call it is.
- **The iPhone at large text sizes.** The chat no longer runs off the sides of the screen, memory shows names in full, and the app reconnects as soon as you open it again.

Requires macOS 15 or later, on Apple silicon or Intel. This is a preview; expect rough edges, and please report them.
